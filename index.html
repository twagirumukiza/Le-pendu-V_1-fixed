📖 Règles du jeu

Principe de base

Un mot secret est choisi. Tu vois seulement sa longueur (des tirets _). Propose des lettres une par une : si la lettre est dans le mot, elle apparaît à sa place ; sinon, une partie du pendu se dessine. 6 erreurs et le pendu est complet — la partie est perdue. Trouve toutes les lettres (ou le mot entier) avant ça pour gagner.

🧍 Mode Solo

Choisis un thème (animaux, cuisine, géographie, informatique & cyber, sport, cinéma & culture...) et une difficulté (facile / moyen / difficile, selon la longueur du mot). Le mot est tiré au hasard dans ce thème. Tu peux proposer une lettre à la fois, ou tenter directement le mot entier à tout moment.

👥 Multijoueur — Manche collective

Le mot est tiré automatiquement selon le thème et la difficulté choisis par l'hôte à la création du salon. Les joueurs proposent une lettre chacun leur tour. Mais à n'importe quel moment, même hors tour, n'importe quel joueur peut tenter de deviner le mot complet via le champ dédié. S'il a raison, il gagne immédiatement. S'il a tort, ça compte comme une erreur pour le groupe. Si le pendu se complète, tout le monde perd.

🔑 Multijoueur — Mot secret

L'hôte choisit lui-même un mot en créant le salon, puis invite ses camarades avec le code (ou le lien de partage). L'hôte ne joue pas — il regarde. Les autres joueurs devinent à tour de rôle, avec la même possibilité de tenter le mot entier à tout moment. Si les joueurs trouvent le mot, ils gagnent. Si le pendu se complète avant, c'est l'hôte qui gagne.

Partager un salon

Une fois un salon créé, utilise le bouton "🔗 Partager le lien du salon" dans le lobby pour envoyer une invitation directe — tes camarades n'auront plus qu'à taper leur nom.
